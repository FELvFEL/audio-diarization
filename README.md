### РАЗРАБОТКА СИСТЕМЫ АВТОМАТИЧЕСКОЙ ДИАРИЗАЦИИ И КОЛЛИЧЕСТВЕННОЙ ОЦЕНКИ УСТНОГО УЧАСТИЯ В ГРУППОВЫХ ДИСКУССИЯХ НА БАЗЕ АУДИОПОТОКА

## О проекте

Проект предназначен для исследования методов автоматической диаризации многоголосых аудиозаписей.

В проекте проверяются следующие модели:

- pyannote Community-1;
- NVIDIA NeMo Sortformer;
- NVIDIA NeMo Clustering + MSDD.

Для проверки используются записи и ручная разметка корпусов AMI Meeting Corpus и ICSI Meeting Corpus.

Каталоги для загрузки аудиозаписей:

- [AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/download/);
- [ICSI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/icsi/download/).

## Возможности

- запуск диаризации локально или в Google Colab;
- обработка аудио на CPU и GPU;
- преобразование входного аудио с помощью FFmpeg в одноканальный WAV PCM 16 бит с частотой дискретизации 16 кГц;
- автоматическое определение числа говорящих или указание известного количества, если это поддерживается моделью;
- настройка VAD, порога MSDD и максимального числа одновременно говорящих для NeMo Clustering + MSDD;
- сохранение результата диаризации в JSON с началом, окончанием и номером говорящего;
- вывод времени выполнения и пикового использования RAM или VRAM;
- загрузка эталонной разметки AMI и ICSI по имени встречи;
- преобразование исходной XML-разметки AMI и ICSI в используемый формат JSON;
- построение эталона на основе слов или сегментов;
- учёт сдвига от начала записи и длительности исследуемого фрагмента;
- автоматическое сопоставление имён говорящих в эталоне и результате диаризации;
- расчёт пропуска речи, ложной речи, путаницы говорящих и DER;
- расчёт JER для каждого говорящего и среднего JER;
- вывод длительности и доли речи каждого говорящего в эталоне.

## Диаризация аудио

Для диаризации нужно выбрать ноутбук с требуемой моделью и способом запуска. Файлы с окончанием `_local.ipynb` предназначены для локального запуска, а файлы с окончанием `_colab.ipynb` - для Google Colab.

В ноутбуке нужно указать или загрузить аудиофайл, при необходимости задать число говорящих и последовательно выполнить все ячейки. Для pyannote Community-1 также требуется токен Hugging Face. Аудио автоматически преобразуется в одноканальный WAV с частотой 16 кГц, после чего запускается модель.

Результат выводится в виде информации о времени диаризации и использованных ресурсов памяти, а также таблицы с началом, окончанием и номером говорящего и сохраняется в JSON. Этот JSON можно передать программе `calculate_der.py` для сравнения с эталонной разметкой.

## Запуск calculate_der.py для анализа результатов диаризации

Запуск:

```
python calculate_der.py
```

После запуска программа последовательно запрашивает:

1. Источник эталонной разметки: AMI или ICSI.
1. Имя встречи, например `ES2002a` или `Bmr002`.
1. Путь к JSON-файлу с результатом диаризации.
1. Способ построения эталона: по словам или по сегментам.
1. Сдвиг фрагмента относительно начала исходной записи в секундах.
1. Длительность фрагмента в секундах.

 Программа скачивает необходимые файлы AMI или ICSI, создаёт эталонный JSON и после завершения удаляет временные файлы. Полученный эталон сохраняется в `content/reference_json_files`.

В результате выводятся длительность эталонной речи, пропуск речи, ложная речь, путаница говорящих, DER, JER каждого говорящего и средний JER.

## Основные файлы

`pyannote_diarization_local.ipynb` - локальный запуск pyannote Community-1.

`pyannote_diarization_colab.ipynb` - запуск pyannote Community-1 в Google Colab.

`nemo_sortformer_diarization_local.ipynb` - локальный запуск NVIDIA NeMo Sortformer.

`nemo_sortformer_diarization_colab.ipynb` - запуск NVIDIA NeMo Sortformer в Google Colab.

`nemo_clustering_msdd_diarization_colab.ipynb` - запуск NVIDIA NeMo Clustering + MSDD в Google Colab.

`calculate_der.py` - основная программа для подготовки эталонной разметки и расчёта DER и JER.

`convert_ami_annotations_to_json_by_words_trancription.py` и `convert_ami_annotations_to_json_by_segments.py` - преобразование разметки AMI в JSON.

`convert_icsi_annotations_to_json_by_words.py` и `convert_icsi_annotations_to_json_by_segments.py` - преобразование разметки ICSI в JSON.

`ami_annotations_download.py` и `icsi_annotations_download.py` - загрузка файлов ручной разметки.

`word_intervals.py` - чтение временных интервалов слов из XML-разметки и объединение пересекающихся интервалов.

`reference_json.py` - общие функции для конвертеров: чтение JSON-файла, созданного моделью диаризации, обрезка загруженной эталонной разметки по сдвигу и длительности аудиофрагмента и сохранение эталона в отдельный JSON-файл.

`speaker_mapping.py` - автоматическое сопоставление говорящих по наибольшему совпадению речи во времени.

`diarization_metrics.py` - расчёт DER, его составляющих и JER.

Файлы `der_comparison_results_*.md` содержат результаты проведённых экспериментов для отдельных записей.

## Папка content

`content/audio_files` - аудиофрагменты используемые для сравнения моделей.

`content/diarization_json_files` - результаты работы моделей в формате JSON.

`content/reference_json_files` - эталонная разметка, преобразованная в JSON.
